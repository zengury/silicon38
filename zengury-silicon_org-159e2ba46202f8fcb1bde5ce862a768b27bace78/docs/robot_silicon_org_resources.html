Robot Silicon Org

十四个机器人专家领域的合法资料入口。每个节点都可以发展成一个可调用的 skill：读资料、建模型、诊断问题、设计实验、给出落地方案。

说明：这里不放盗版下载链接，只放官方、开放课程、开放教材、出版社页面、论文和项目文档。付费书籍走出版社/图书馆/学校资源，开放教材直接从作者或项目站点阅读。

math-foundation

数学基础：线代、微积分、概率、优化、数值方法。

核心资料

  • Convex Optimization - Boyd & Vandenberghe
  • Introduction to Robotics and Perception
  • Stanford CS223A Introduction to Robotics

Skill: robot-math-translator，把工程问题翻译成变量、约束、目标函数和不确定性。

kinematics-expert

运动学：坐标变换、正/逆运动学、Jacobian、工作空间。

核心资料

  • Modern Robotics official site
  • Modern Robotics preprint PDF
  • Stanford Engineering Everywhere CS223A

Skill: kinematics-debugger，检查 DH/SE(3) 表达、IK 可解性、Jacobian 奇异点。

dynamics-expert

动力学：刚体动力学、Lagrange/Newton-Euler、接触、摩擦。

核心资料

  • Rigid Body Dynamics Algorithms - Featherstone
  • Robotics: Modelling, Planning and Control - Springer
  • MIT Underactuated Robotics

Skill: dynamics-model-auditor，审查质量矩阵、科氏项、重力项、接触模型和仿真一致性。

control-engineer

运动控制：PID、频域分析、稳定性、状态空间、系统辨识。

核心资料

  • Feedback Systems - Astrom & Murray
  • Control Tutorials for MATLAB and Simulink
  • Feedback Systems PDF

Skill: control-loop-diagnostician，根据响应曲线判断欠阻尼、延迟、积分饱和、噪声放大。

force-control-expert

力控：阻抗/导纳控制、接触任务、柔顺控制、末端执行器。

核心资料

  • Robotics: Modelling, Planning and Control
  • Stanford CS223A force control topics
  • Modern Robotics force control chapter resources

Skill: contact-task-reviewer，判断接触任务是否需要力控、位置控、混合控制或安全限幅。

mpc-optimizer

MPC/优化控制：代价函数、约束、QP/NLP、WBC、实时优化。

核心资料

  • Convex Optimization
  • Berkeley MPC course materials
  • OSQP documentation

Skill: mpc-formulation-designer，把机器人任务写成状态、控制、约束、代价和求解器选择。

motion-planner

运动规划：搜索、采样规划、轨迹优化、避障、任务规划。

核心资料

  • Planning Algorithms - Steven LaValle
  • MoveIt 2 Documentation
  • OMPL documentation

Skill: planner-selector，在 A*、RRT、PRM、CHOMP、TrajOpt、MoveIt pipeline 之间做选择。

perception-engineer

感知：目标检测、3D 重建、点云、传感器融合、状态估计。

核心资料

  • Deep Learning - Goodfellow, Bengio, Courville
  • Stanford CS231n
  • Open3D documentation

Skill: perception-pipeline-architect，设计相机/IMU/LiDAR/深度数据到状态估计的 pipeline。

slam-navigation

SLAM/导航：定位、建图、回环检测、图优化、Nav2。

核心资料

  • Probabilistic Robotics - MIT Press
  • Probabilistic Robotics author site
  • Nav2 documentation

Skill: slam-nav2-debugger，诊断 TF、map-odom-base_link、AMCL、costmap、planner/controller 问题。

world-modeler

世界模型：状态表示、因果、环境理解、预测、仿真表示。

核心资料

  • Introduction to Robotics and Perception
  • Deep Learning
  • World Models - Ha & Schmidhuber

Skill: robot-world-state-designer，设计机器人可查询、可验证、可更新的环境状态 schema。

rl-policy-engineer

强化学习：PPO、reward、exploration、sim2real、policy optimization。

核心资料

  • Reinforcement Learning: An Introduction
  • OpenAI Spinning Up
  • An Introduction to Deep Reinforcement Learning

Skill: rl-experiment-designer，设计 reward、观测、动作空间、baseline、ablation 和 sim2real 风险。

vla-agent-engineer

VLA/具身智能：视觉-语言-动作模型、task grounding、多模态策略。

核心资料

  • SayCan project
  • RT-2: Vision-Language-Action Models
  • RoboCat - Google DeepMind
  • OpenVLA paper

Skill: vla-to-runtime-gate，把自然语言/视觉意图转成受约束、可审计、可拒绝的机器人 intent。

ros-runtime-engineer

ROS/机器人系统：ROS 2、topic/service/action、ros2_control、MoveIt、runtime。

核心资料

  • ROS 2 documentation
  • ros2_control documentation
  • Drake robotics toolkit
  • MoveIt 2

Skill: ros-runtime-architect，设计 node graph、接口、生命周期、日志、故障恢复和安全 gate。

robot-product-strategist

应用创新：场景选择、产品定义、任务拆解、商业可行性。

核心资料

  • Robotics Business Review
  • International Federation of Robotics
  • McKinsey: automation and robotics

Skill: robot-application-scout，评估场景痛点、机器人能力边界、ROI、部署风险和 demo 设计。
