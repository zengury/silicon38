# Cyberpunk 西游记 — UX Design Brief

## 设计愿景
将「西天取经」团队重新想象为一个来自 2077 年的全栈开发组织。他们在赛博空间的"西天"（终极代码库）取经，沿途对抗的不是妖怪，而是 Bug、技术债、遗留系统。

## 角色重塑

| 原角色 | Cyberpunk 身份 | 视觉特征 |
|--------|---------------|---------|
| **唐僧** 🙏 | **Neon Monk** — 系统架构师/项目经理 | 数据袈裟（流动代码经文）、全息光环、AR 禅杖显示项目仪表盘 |
| **八戒** 💡 | **Glitch Pig** — 产品黑客/增长负责人 | 赛博义眼（数据分析）、霓虹粉皮肤、AR 需求面板悬浮 |
| **猴哥** 🐒 | **Silicon Ape** — 核心开发者/全栈忍者 | 机械臂（多线程编码）、数据金箍（脑机接口调试器）、闪电披风 |
| **沙僧** 🧪 | **Iron Monk** — DevOps/QA 工程师 | 重型机械外骨骼、终端头显（跑测试）、流沙数据瀑布 |
| **白龙马** 🐴 | **Chrome Dragon** — 客户成功/布道师 | 铬合金鳞片、全息投影仪（演示）、光缆尾巴连接客户 |

## 视觉语言

### 配色方案 — "霓虹暗境"
```
背景:    #0a0a0f (深渊黑) → #1a1a2e (暗蓝紫)
主霓虹:  #00f0ff (赛博青) — 唐僧
         #ff00aa (霓虹粉) — 八戒  
         #ffd700 (数据金) — 猴哥
         #00ff88 (终端绿) — 沙僧
         #bf80ff (全息紫) — 白龙马
强调:    #ff3333 (错误红)
文字:    #e0e0f0 (冷白)
面板:    rgba(10,10,30,0.9) 半透明 + border 霓虹
```

### 字体
```
标题: "Orbitron" 或 "Rajdhani" (几何无衬线)
正文: "JetBrains Mono" 或 "Share Tech Mono" (等宽技术感)
中文: "Noto Sans SC"
```

### 视觉元素
- **全息扫描线**: 卡片边框使用动画扫描线效果
- **数据粒子**: 背景浮动二进制粒子
- **霓虹辉光**: box-shadow 多层 neon blur
- **终端窗口**: 对话面板模拟终端 `>_` 提示符
- **数据流连接线**: agent 之间用发光的 SVG 数据流连接
- **故障艺术 (glitch)**: 状态切换时短暂 glitch 效果
- **HUD 覆盖层**: 四角有扫描框和坐标数据

## 交互设计

### 状态动画
- **idle**: 暗淡呼吸灯
- **thinking**: 数据粒子围绕头像旋转 (processing ring)
- **working**: 霓虹脉冲，扫描线加速
- **delegating**: 数据包从唐僧飞向目标
- **speaking**: 终端光标闪烁 + 文字逐字输出 (打字机效果)
- **delivered**: 绿色确认脉冲 + checkmark glitch
- **error**: 红色闪烁 + glitch 抖动

### 过渡
- agent 激活: 卡片霓虹边框从暗→亮 (0.3s ease)
- 消息到达: 终端区域短暂扫描线扫过
- 委派: 数据包粒子动画沿连接线飞行

## 用户旅程 (顾问视角)

1. 打开控制台 → HUD 启动动画 → agent 雷达图渲染
2. 选择/创建客户 → 终端显示 `$ ssh journey://客户名`
3. 输入需求 → 发送按钮变为 `[EXECUTE]`，脉冲效果
4. 唐僧 thinking → 光环旋转
5. 委派徒弟 → 数据包飞行 → 徒弟卡片激活
6. 接收交付 → 终端逐行显示结果
7. 文件生成 → DATA VAULT 出现新条目 + 扫描线
