## 2. Thompson Sampling Policy Router

Symbolist edge selection replaced with probabilistic sampling:

```
Before:  triggers/may_trigger + hard conditions → activate if score ≥ threshold
After:   Beta(α,β) → Thompson sample → top-k activate
```

Key properties:
- Validated edges (144 in relations.yaml) keep high α, consistently sampled
- Unvalidated edges (LLM cognitive, structural priors) have wide priors, occasionally explored
- No edge permanently excluded — just very low probability
- Hard constraints preserved: L3 cannot forward-activate L1, meta nodes excluded

## 7. Architecture: Three-Layer Learning

```
Layer 0: LLM Cognitive → role-pair correlation scores → Beta priors
Layer 1: Validated Edges → relations.yaml 144 edges → override corrections
Layer 2: Runtime Learning → Thompson Sampling + Bayesian → continuous evolution
```

Cold start: α=0.5, β=12 for unknown cross-domain edges.  
Confident edges: α=200+, samples=17+ from production traces.  
Suppressed edges: domain-mismatch priors at 0.04.

## 8. Key Decisions

1. **Thompson over pure neural**: interpretable Beta distributions, auditable edge weights, bounded exploration
2. **Domain suppression over task-type gating**: simpler, fewer manual annotations, self-correcting via Bayesian
3. **Evaluates direction fix**: evaluator→producer should never activate; only producer→evaluator feedback
4. **Default enabled**: Thompson Sampling on by default; symbolist mode via `use_thompson_sampling: False`
